FactoryPulse: Predictive Maintenance & OEE Command Center

Team ICE · CoCo CLI Hackathon (GCC Edition) · converges OT sensor streams with ERP and CMMS context to predict failures, auto-create work orders and lift OEE.

Source code on GitHub Release: demo video + submission deck How to run it
PredictGradient-boosting model on hourly OT features plus maintenance context: probability of failure in the next 24 h, with the drivers behind each score.
ActCRITICAL alerts open a P1 work order automatically, with guardrails: dedupe, one open work order per asset, auto-resolve, rule-based sensor limits.
ExplainRoot cause in natural language from a grounded evidence pack (local IBM Granite 4.0 1B), plus verified queries and guarded text-to-SQL.
MeasureOEE (Availability × Performance × Quality) per asset, line and plant, computed from ERP production orders and linked to the physical cause.
The live Streamlit app runs server-side Python and therefore cannot be hosted on GitHub Pages; see RUNNING.md for the Streamlit Community Cloud deployment.
